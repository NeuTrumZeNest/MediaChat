# Временный доступ через интернет

Запуск из папки проекта (Node 24, PostgreSQL запущен):

```sh
cd ~/Desktop/media-chat
npm run build:share
npm run share
```

Скрипт получает бесплатный временный HTTPS-домен localhost.run и запускает production
Next.js + Socket.IO на 127.0.0.1:3000 с точным APP_ORIGIN. Cookie Secure/HttpOnly/SameSite=Lax.
Терминал должен оставаться открытым. Остановка обоих процессов: Ctrl+C.
При смене кода остановить публичный запуск и повторить сборку. Порт 3000 должен быть свободен. Для текущей версии команды build:share/share используют каталог .next/groups-release. Адрес при новом
запуске меняется. При ротации домена провайдером скрипт печатает новый адрес и
перезапускает приложение с новым APP_ORIGIN. Старую ссылку нужно заменить вручную.
После полного обрыва SSH повторить команду запуска. Бесплатный сервис не даёт SLA.
SSH keepalive: 30 секунд, 3 пропуска. Личные SSH-ключи и агент не используются;
проверка ключа сервера сохраняется в игнорируемом .next/tunnel-known-hosts.

Mac должен оставаться включённым и подключённым к интернету. Закрытие крышки может
прервать доступ. PostgreSQL остаётся только на localhost, uploads не публикуются
как статическая директория. Плановая очистка отключена на время тестового запуска;
удаление конкретного сообщения продолжает очищать его файлы штатным обработчиком.
Регистрационный лимит сейчас общий для адреса локального прокси (5/час), это
ограничение временного тестирования, не конфигурация публичного выпуска.

## Диагностика 17 ноября 2026

У cloudflared 2026.11.0 воспроизведён DNS lookup на [::1]:53: connection refused.
/etc/resolv.conf (ссылка на /var/run/resolv.conf) не содержит nameserver, хотя
scutil показывает scoped Wi-Fi DNS роутера. Запрос SRV напрямую через роутер
192.168.0.1 и через 1.1.1.1 успешен; TCP region1.v2.argotunnel.com:7844 доступен.
Согласованная ручная настройка Wi-Fi DNS на 192.168.0.1 не обновила этот файл и
не исправила cloudflared. Настройка возвращена в исходный DHCP/автоматический
режим через networksetup -setdnsservers Wi-Fi Empty. Причина пустого файла
и QUIC-таймаутов не установлена; блокировка UDP только по этим данным не доказана.

DNS override у cloudflared run требует именованный туннель; Quick Tunnel не принял
параметр и не использовал переменную TUNNEL_DNS_RESOLVER_ADDRS. GODEBUG=netdns=cgo
также не исправил запрос SRV. Системные файлы вручную не редактировались.
VPN Happ Plus отображался Connected до и после отката. Конфигурации VPN не менялись.
Работа из сетей России/Украины требует проверки реальным получателем: локальный
тест через внешний HTTPS-домен сам по себе её не доказывает.

Официальные источники:

## Проверки текущего запуска

Production-сборка и ESLint прошли. Через внешний HTTPS-домен проверены регистрация,
вход, Secure/HttpOnly cookie, Socket.IO WebSocket, единственность A–B, ответы,
редактирование, запреты для третьего пользователя, изображение/аудио/видео/документ
в обе стороны, точные байты оригиналов, Range, защищённые превью/постеры,
пагинация и восстановление подписки. Проверка интерфейса Chrome выполняется отдельно.
.env, .git/config и media-chat.zip через внешний адрес возвращают 404;
/api/me без сессии — 401. PostgreSQL слушает только localhost. SESSION_SECRET
задан и имеет длину не менее 32 байт; значение не выводилось.

Браузерная проверка завершена через scripts/verify-external-ui.mjs: две временные
сессии Chrome, личный текст в обе стороны, загрузки через меню (все четыре HTTP 201),
просмотр изображения, воспроизведение аудио/видео, скачивание оригинала документа
и перезагрузка прошли, ошибок JavaScript нет. Для внешнего сервиса потребовались
увеличенные сетевые таймауты (навигация 120 секунд, вся очередь файлов до 300 секунд).
Первый полный прогон остановился на page-load 30 секунд, второй — на ожидании всей
очереди 90 секунд; это не отмечено как успех. Финальный отдельный прогон прошёл.
Тестовые аккаунты/диалоги/сообщения/файлы удалены. В тестах не проверялись файлы 2 ГБ
и фактические подключения из России/Украины. Внешний адрес оставлен работающим;
после остановки/ротации получить новый командой запуска выше.
