## Выполнено: безопасность и документы

- Проверка владения изображением/аудио/документом до записи сообщения, независимо от доступности файла для чтения.
- Socket.IO: проверка Origin, HS256, отключение по exp и проверка exp перед каждым сообщением; удалённый пользователь не может продолжать отправку. Общий чат использует комнату general; входящие conversationId пока явно отклоняются.
- Регистрация/вход: лимиты запросов, типы и длины полей, 400 для неверного JSON, ограничение фактического тела 8 КиБ. Регистрация не принимает пароль только из пробелов и управляющие символы в имени.
- Загрузка медиа ограничивает фактически прочитанные байты, а не только Content-Length.
- Документы: серверная валидация формата/имени, UUID, приватное хранение, метаданные, HTTP API, Socket.IO, история, карточка, скачивание, предпросмотр имени/размера и прогресс.
- PDF/TXT/CSV/DOCX/XLSX/PPTX/ZIP до 25 МиБ. ZIP проверяется по структуре и CRC с пределом распаковки 100 МиБ, без небезопасных путей. Не антивирус и не полноценный парсер PDF/Office.
- Миграция `20261111T0855_add_documents`: nullable documentUrl/clientMessageId + unique clientMessageId; применена, db ref продвинут до 0f3859b…; db verify подтверждает соответствие DDL и контракта.
- Retry отправки сохраняет nonce и загруженные URL, синхронный lock исключает двойной клик; серверный unique защищает конкурентные повторы. Старые клиенты без nonce по-прежнему принимаются, но без гарантии идемпотентности.
- История объединяется с realtime по id; reconnect обновляет историю. N+1 авторов заменён include/select. Пагинация пока не реализована.
- Исправлены эффекты предпросмотра изображения; ESLint исключает только сгенерированные декларации Prisma. Дизайн музыкального плеера не изменён.
- Дампы исключены из Git. Контрольный коммит автоматически не создавался.

### Ограничения до беты

Нет UI/API личных переписок и уникального ключа пары; нет пагинации истории; нет общих квот хранения и сборщика неиспользованных загрузок. Лимиты in-memory на один процесс, за reverse proxy IP объединяется без дополнительной настройки. JWT stateless: очистка cookie не отзывает украденную копию токена; другие вкладки пока не синхронизируют logout. Аудио проверяется по сигнатуре, не полным декодированием. Адаптивность sidebar и доступность image viewer требуют отдельного прохода. Проверки документов структурные, не гарантия безопасности содержимого. Архивы проверяются синхронно с ограничением распаковки; для высокой нагрузки нужно вынести обработку в worker/очередь.
